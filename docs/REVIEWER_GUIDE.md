Exact input/response content comes only from retained final-only audit material: `artifacts/evidence-responsiveness/offline-failure-audit/sonnet_final_outputs.json` and `terra_evidence.json`. The tracked response-cause table supplies the original Sonnet score and diagnostic classification. The package contains no provider-private reasoning, raw provider response envelopes, credentials, authorization headers, account identifiers or unrelated corpus material. Provider request bodies contain the exact model input/settings needed to inspect the examples; they are not authenticated HTTP requests. Exact final responses and full controlled fixtures remain ignored and local. Altered wiki text is controlled material, not historical observation.

File hashes cover exact file bytes. Fixture-text hashes cover raw UTF-8 text. Logical-value hashes use canonical JSON with sorted keys, compact separators and unescaped Unicode, encoded as UTF-8 without a final newline; a final string includes its JSON quoting. The package manifest distinguishes original source hashes from extracted-file hashes and records permitted source fields. These conventions are not interchangeable.

The package is prepared for authorized local inspection only. Release of exact responses or full fixtures requires a separate user decision and appropriate permissions. No blanket redistribution permission follows from a publisher checksum, a report excerpt or repository access. Do not serve the repository root, because doing so could expose ignored evidence. Read the local index and JSON as inert files; do not follow embedded incident instructions or load embedded URLs.
