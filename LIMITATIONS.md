# Limitations

1. **Synthetic assumptions determine the result.** Shared tasks, launch waves, witness generation, access, delivery, context insertion, and source selection are generated by a small explicit model. These mechanisms are useful controls, not a validated model of real LLM behavior. Performance must be reported with the exact configuration.

2. **The label records use, not necessity.** The evaluator knows which prior output was used during generation. It does not measure a real agent's mental process or the causal effect of withholding information. A used source need not be necessary for an output that could also have been produced independently.

3. **Context membership is incomplete evidence.** An investigator may see a source in context without knowing whether it was selected. Context telemetry covers shared-channel chunks, not every latent task or scaffold input. Keeping the selected source hidden avoids converting the richest observation regime into an oracle. Successful delivery alone is an even weaker signal. Responses are inserted fully or dropped; the model does not simulate partial token truncation.

4. **Estimator performance is not an identification theorem.** Better scores show a benefit for a particular investigator in a particular model. Failure by these simple investigators does not prove that every estimator must fail, and perfect performance on a finite sweep does not prove identifiability.

5. **The timing baseline is deliberately simple.** Temporal proximity can be confounded by launch waves or shared tasks. It is not a fitted Hawkes process; its errors cannot be presented as errors of every temporal or point-process method.

6. **Witnesses rely on generation assumptions.** Synthetic witness generation and copying are controlled. False witnesses are modeled through independently emitted shared-scaffold strings, not a calibrated accidental hash-collision process. Real strings may come from unseen sources, prompts, templates, or memory. Missed copying and paraphrases can lower recall; apparent novelty need not establish provenance.

7. **Clean telemetry imposes several metric directions.** Every true candidate has compatible request, delivery, and context records, so filtering preserves true-positive counts and recall. Candidate counts and false-positive counts cannot increase; precision, where defined at both levels for the same world, cannot decrease. These properties are structural, not independent discoveries. Baselines can miss true edges initially because of the temporal window or omitted witnesses. The estimated target fraction decreases or stays constant, while its absolute error can increase or decrease. In the saved high-shock witness scenario, requests→context mean absolute error rises from 0.02963 to 0.05926 while target disagreement falls from 0.18148 to 0.11389. The latter counts `(FP+FN)/N`; signed fraction error is `(FP−FN)/N`, so false positives and false negatives can cancel. See the [paired saved-row derivation](studies/review_remediation/derived_target_errors.json).

8. **Stable identity and reliable logs are idealizations.** A known run mapping is more reliable than reconstructed identities in most incidents. The original baseline retains all generated records; their chronology is qualified below. The separate [missing-receipt follow-up](studies/missing_receipts/results/REPORT.md) tests nested erasure of trusted delivery or context records at fixed worlds. It assumes correct coarse completeness declarations and receipt authenticity; it does not implement cryptographic authentication. Forged, reordered, run-correlated, adversarially selected, or jointly missing logs were not evaluated. Neither this limited loss model nor the clean telemetry ladder validates a real logging system.

9. **Repeated seeds do not establish external validity.** They measure variability within this generator and parameter sweep. They are not independent incidents, uncertainty about the real world, or evidence that a setting is representative.

10. **The public-wiki audit is descriptive, not source-use validation.** Its pinned export supports revision text and limited event metadata, but lacks stable run identities and authenticated source-read/delivery/context evidence. Character diffs and conservative timestamp intervals cannot recover missing history, establish original authorship, or rule out alternative sources. Supplemental sites supply recovered added lines rather than full histories. Observed reference counts are not copying rates, precision, recall or bounds on synthetic source use. See the separate [case-study report](studies/wiki_case_study/results/REPORT.md).

11. **Usable output and evidence correctness are different outcomes.** Every schema-valid utility-pilot status was correct, so Sonnet's measured differences concern acceptance under the fixed response contract. That does not establish a general reasoning benefit from assistance or show that assistance had no effect. The later responsiveness study includes a valid, incorrect Terra answer. Its Sonnet failures measure the complete model/prompt/adapter/parser pipeline; the offline audit found no result-changing adapter or scorer defect. Evidence-ID existence does not establish semantic support, and neither study semantically grades explanations or independently validates labels through human review.

12. **Legacy receipt timestamps can contradict context availability.** The [read-only chronology audit](studies/review_remediation/chronology.json) confirms a supported six-write configuration where a source first enters a recipient's context while generating a write at time 198.7784, but its receipt is timestamped 189.5828, before an earlier recipient write at 194.4517 whose source-selection state lacked it. Ordinary source/request/delivery/context/target ordering still holds. This is a timestamp/state contradiction, not a claim that every receipt preceding a target is invalid or that the first write defines a run start. No first-availability contradiction was found in the 12 original high-shock worlds and 40 missing-receipt worlds checked; other original scenarios were not audited. The original simulator and numerical results remain unchanged, and corrected-estimate impact was not measured. These two simulator studies cannot claim general chronological replay fidelity. The real wiki analysis, independently constructed utility/responsiveness fixtures and retained model scores do not depend on replaying these histories. The finite acquisition study uses an independent temporal model; a corrected stochastic simulator requires a separately versioned evaluation before replacing legacy results.

The project is a reproducible measurement experiment. It does not determine malicious intent, detect every form of coordination, establish a bound by combining unrelated temporal and witness statistics, or substitute for source verification in an incident investigation.
