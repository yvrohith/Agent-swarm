What this experiment measures

How observation limits and attribution rules affect recovery of a known synthetic transmission graph. The temporal method starts from nearby same-page writes; the witness method starts from exact witness-token overlap. Both filter candidate edges using the evidence available in the selected regime. Candidate sets shrink by construction. In this clean-log baseline, complete logs preserve true edges and recall; precision gains partly follow these assumptions. Fewer false positives alone are not an empirical discovery. The separate missing-receipt study tests erased records; altered record contents remain untested.

What remains unobserved

A request need not be delivered. Delivered information need not enter context. Information in context need not change a decision. Context visibility records included shared-channel chunks, not the full harness state or which source was selected or used. The simulator’s ground truth makes evaluation possible; real traces usually do not provide that truth.
